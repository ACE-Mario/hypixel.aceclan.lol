Ace Clan Hypixel Mod

Track your SkyBlock drops live with the clan, and see everything in your sacks, ender chest, backpacks and island chests in one place. Your drops show up in Discord through Jerry, with a leaderboard for everyone playing.

Minecraft 26.2 Fabric Client-side only Version 1.13.1
⬇ Download the mod ace-clan-hypixel-1.13.1.jar · 100 KB

The mod reads chat and menus and draws on your screen. The only commands it ever sends are when you click an item in the storage viewer: /gfs, or the command that opens that ender chest page or backpack.

Set it up

  1. Install Fabric for Minecraft 26.2 Use the Fabric installer, or make a Fabric 26.2 instance in a launcher like Modrinth or Prism.
  2. Add Fabric API Download Fabric API for 26.2 and put it in your mods folder.
  3. Add the Ace Clan Hypixel mod Download the jar above and put it in the same mods folder, then start the game.
  4. Link to Jerry In the clan Discord, type !jerry link. Jerry sends you a private message with a command. Paste that command into Minecraft chat once. Don't share it.
  5. Start tracking In Minecraft, type /jerry gui and press Start on a tracker, or use !jerry start powder in Discord.

Storage viewer

📦 Sacks at a glance

Press B or type /jerry storage for one searchable grid of everything in your sacks. No API key needed.

🖱️ Quick take-out

Left click takes a stack, right click takes 1, shift click takes as many as fit. Uses Hypixel's own /gfs.

🎒 Ender chest & backpacks

Every ender chest page and backpack is in the grid too. Click an item and it opens the exact page or backpack it's in.

⭐ Favorites

Hover an item and press F to star it and pin it to the top, on its own row. Change the key in Controls under Ace Clan Hypixel.

👤 Per profile

Each SkyBlock profile keeps its own storage, saved between games. Switch profiles from the dropdown at the top.

🧰 Island chests

Chests you open on your private island are remembered. Click an item and its chest lights up through walls.

⚙️ Settings screen

Turn chest memory and each tracker on or off with /jerry settings.

Sacks, ender chest and backpacks come from Hypixel's API when you open the viewer (your Inventory API needs to be on). Sacks stay live from the [Sacks] chat messages, and opening a sack, ender chest page or backpack updates it straight away.

Commands

/jerry guiIn Minecraft. Open the tracker panel: start, stop and see live totals.
/jerry storageIn Minecraft. Open the storage viewer for your sacks, ender chest, backpacks and island chests. The B key does the same.
/jerry storage highlightIn Minecraft. Outline every island chest the mod remembers, so you can spot the ones you haven't opened yet.
/jerry mapIn Minecraft. Link to the live clan map. Turn on Share my location in /jerry settings to show up on it.
/jerry nucleusIn Minecraft. Your Crystal Nucleus runs: this session and the total on each profile. Each run also shows its number in chat.
/jerry settingsIn Minecraft. Toggle features and choose which of your drops are sent.
/jerry start <tracker>In Minecraft. Start a tracker. /jerry stop <tracker> stops it.
/jerry statusIn Minecraft. Check you're connected and what's running.
!jerry linkIn Discord. Get your private link code by DM.
!jerry start <tracker>In Discord. Start a tracker in that channel. Short names work, like powder or rare.
!jerry statusIn Discord. See which trackers are running.

Problems?

The game says the mod needs a different version

The mod is for Minecraft 26.2 with Fabric Loader 0.20.1 or newer. Check your instance is 26.2 and Fabric, not Forge or NeoForge.

/jerry gui says "Not linked" or "Jerry offline"

"Not linked" means you still need to run !jerry link in Discord and paste the command into Minecraft. "Jerry offline" means the bot isn't running right now. Try again later.

Jerry can't DM me the code

In Discord, right-click the server, open Privacy Settings and allow direct messages from server members. Then run !jerry link again.

My drops aren't being counted

The tracker has to be running (green in /jerry gui), and it has to be switched on for you in /jerry settings. If it still misses drops, say so in the clan Discord: which tracker and what you were doing.

The storage viewer is empty or out of date

Press Sync. If it says the Inventory API is off, turn it on in SkyBlock under Settings → API Settings. Check the profile dropdown shows the profile you're on. Chests only show up once you've opened them on your island with chest memory on. If a chest still isn't saved, type /jerry storage debug right after closing it and send the result in the clan Discord.

Is this allowed on Hypixel?

The mod only reads what the game already shows you and draws overlays. It doesn't automate anything: the storage viewer sends one command per click, the same as typing it. As with any mod, you use it at your own risk.
